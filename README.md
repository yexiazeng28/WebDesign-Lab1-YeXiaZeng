• What is a website, and how is it different from a web application?

A website is like a place on the internet where you can see information, pictures, or videos, kind of like a digital poster. A web application is different because it lets you actually do stuff online, like fill out forms or use tools through your browser instead of just reading or watching.


• Why do you think organizations (like offices or schools) need websites?

Schools or offices need websites so they can share important updates, schedules, or resources with students, parents, or employees. It’s an easy way for everyone to find info anytime they need it.


• What challenges did you encounter while creating your first repository?

When I made my first repository on GitHub, I found it confusing to figure out how to organize my files and use commands like “commit” or “push.” I wasn’t sure what to put in the README file either, so I struggled to explain my project properly.


• How might this practice of documentation (README) help in future projects?

Writing a README can really help later on because it’s like writing instructions or notes about the project. If you come back to it after a while, or if someone else looks at it, they’ll understand what the project is about and how to use it without asking a bunch of questions.
